## 🛠️ Stack Technique du Portfolio

Ce site web a été conçu comme une *Single Page Application* (SPA) performante :
- **Framework :** React 18 avec TypeScript
- **Bundler :** Vite
- **Styling :** Tailwind CSS & Composants shadcn/ui
- **Routage :** React Router DOM (HashRouter)
- **Hébergement & CI/CD :** GitHub Pages avec GitHub Actions
